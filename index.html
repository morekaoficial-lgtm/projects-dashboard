💬 Como llamar a Kimi (como usar este registro)

1. Usa el PROJECT_ID

Cada proyecto tiene un ID unico. Cuando me pidas algo, usalo asi:

"Actualicemos PRJ-004"

"Arregla el bug de PRJ-003"

"Deploy PRJ-007 otra vez"

Asi no hay confusion entre proyectos similares.

2. Ver la metodologia

Cada tarjeta abajo muestra:

  • Metodologia: como esta hecho y como se deploya
  • Repo: link a GitHub (si tiene)
  • Estado: Activo, En debug, Produccion...
  • Directorio: donde vive el codigo

3. Ejemplo practico

Tu: "Kimi, PRJ-004 no esta recibiendo webhooks de Shopify. Revisalo."

Yo: Voy directo al ML → Bsale Webhook Hub, reviso logs, nginx, PM2... y no toco ningun otro proyecto por accidente.

4. Proyectos sin ID

Si necesitas un proyecto nuevo o no tiene ID aun, dime y le asigno el siguiente numero disponible (PRJ-035, etc.).
